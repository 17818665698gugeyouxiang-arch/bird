# Candle Wings · 飞越行情

在线游玩：https://17818665698gugeyouxiang-arch.github.io/bird/

双击 `index.html` 仍可离线游玩，无需安装。可选登录和最高分同步需要联网，使用同目录的 `cloud.js` 与 `supabase-config.js`。

## 操作

| 操作 | 按键 / 控件 |
| --- | --- |
| 振翅 | 空格、↑、点击游戏区域或触屏 |
| 加仓 | A / 左侧加仓按钮 |
| 减仓 | D / 左侧减仓按钮 |
| 调整比例 | 左侧百分比输入，1–20%，回车完成；输入时仍可按空格振翅 |
| 暂停 / 继续 | P、Esc、右上角按钮 |
| 主动结束 | 平仓离场按钮 |

调仓不暂停，长按 A/D 不会连续下单。默认加仓花费**剩余现金的 10%**，减仓卖出**现有持仓的 10%**；百分比实时按当前余额计算，中途单次加仓和减仓均不得超过 20%；开局投入与结束时的全额平仓不受此调仓限制。

## 本局资金与结算

- 每局重新发放 ¥2,000 模拟资金，可自定义开局投入 0–2,000 元，剩余作为现金。
- 买卖使用操作发生时的小鸟高度对应股价。小鸟越高股价越高，振翅和下落都会影响股价，K 线跟随飞行轨迹。开盘价为 ¥128。股价按小鸟的世界高度使用对数坐标计算，开盘附近保持 7 倍初始敏感度（约每像素 ¥0.70），此后按价格比例变化；最低价为 ¥0.01。镜头移动不会改变价格。按份额持仓、加权平均成本核算；允许零碎份额，无借款或杠杆。买卖各收 1% 游戏手续费（向上取整到分），买入预算包含手续费，卖出到账金额已扣费。
- 总资产 = 剩余现金 + 持仓市值；总盈亏 = 总资产 − ¥2,000。现金用整数分记账，成交所得四舍五入到分。
- 撞柱子、越过上下边界，或总资产按分计价归零，均为失败；即使撞击时盈利也不会算胜利。
- 至少通过 8 组柱子才能主动离场；此前仍可正常加减仓。主动平仓会卖出全部持仓并结束本局：盈利为止盈成功，亏损为亏损离场，持平为平仓离场。
- 不累计、保存或结转任何资金。最高穿越分数保存在浏览器本地；登录后也会同步到当前账号的飞鸟最高分。刷新页面仍从新一局开始。
- 无杠杆且价格保持正值，所以一次正常持仓下跌不会直接亏光本金；破产检查按实际总资产归零触发，不会把空仓或现金全部投入误判为破产。

## 市场与 K 线

红涨绿跌，每 0.16 秒从小鸟实际飞行高度对应的价格采样 OHLC；蜡烛实体约占对应采样间距的 72%，随移动速率调整。通道的世界高度总体向下：普通通道 68% 概率下移 10–24 像素、32% 概率上移 10–28 像素；每第 30、60、90…组独立进行一次 50% 概率判定，命中则在连续 4 个通道内累计上移 180–240 像素，形成大幅反弹。大幅变化自动增加横向间距；生成前使用同一套飞行物理验证参考路径，屏幕右侧提示尚未进入画面的下一通道高度。镜头跟随通道连线，允许长期持续下行，不会在屏幕底部强行反弹。长期不调仓具有负向收益倾向，但不是每局必亏，反弹仍可能带来盈利。

## 验证

`node tests/verify.cjs`

覆盖账户计算、重置、输入与暂停规则、结算、碰撞、帧率一致性和 200 组随机路线模拟。22 项检查通过，包含两种画幅下共 200 条路线通关 40 关，以及鸟高度驱动行情与 K 线、成交账本对账。逻辑测试使用 DOM/canvas 替身。上线后已在浏览器验证启动、边界失败结算、重新开局和账号面板；未进行完整 40 关人工试玩。

上一版保存在 `backups/index.before-trading.html`。

难度：初始移动速度 225，随得分提升至最高 315；普通通道从 180 缩至最低 150，高波动通道从 195 缩至最低 170。每个新通道仍通过物理可达性验证，必要时增大横向间距。

## 交易反馈与复盘

侧栏显示仓位比例，调仓提示支出 / 到账、成交价及手续费。金色虚线表示包含买入手续费的平均成本（卖出手续费另扣），成本超出画面时用箭头提示。结算图按实际成交时刻标记红买绿卖，列出费前价差收益、总费用以及最近 6 笔成交。价差收益减去交易费用等于本局净盈亏。

## 同市场策略对比

运行 `node analysis/compare-strategies.cjs`，用同样的 200 个随机种子分别比较追涨止损、逢跌加仓和一直持有；每 3 秒判断一次，单次 20%，开局投入 600 元，40 关全部平仓。自动飞行仅隔离市场风险，不代表真人胜率。先前结果见 `analysis/strategy-comparison.json` 和 `analysis/strategy-report.md`，它们采用通道报价，恢复小鸟驱动报价后不再代表当前版本。原始模拟报告保留为旧版记录。

## 发布与账号

使用 GitHub Actions 发布到 GitHub Pages，推送 `master` 后自动测试、生成 `dist` 并部署。详见 [DEPLOYMENT.md](DEPLOYMENT.md)。账号入口在左侧面板底部。飞鸟与肘肘猪共用账号；没有账号可注册，用户名为 1–10 位英文字母、密码至少 8 位数字。游客分数不自动合入账号，登录后完成的局才上传；不保存资金和进行中的局。

云端是个人最高分备份，不是防作弊排行榜。切换设备前等待“云端已同步”；当前版本的账号元数据更新不具备跨设备同时写入的原子最大值保证，避免同一账号同时在多台设备游玩。登录状态仅保存在当前浏览器标签页会话中，关闭后可能需重新登录；密码不保存。
